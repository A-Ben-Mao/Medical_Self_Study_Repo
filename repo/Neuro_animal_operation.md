# 1. 脑组织取材与切片

完整的取材-切片流程为：灌流固定 → 取脑 → 后固定 → 脱水 → OCT 包埋 → 冰冻切片。1.1~1.3 已收录对应实操视频；其中**后固定、脱水**的视频资料暂未收录，先以文字交代流程。

## 1.1 灌流固定与取脑

心脏灌流是脑组织预固定的常用方式：先用生理盐水冲净血液，再灌入多聚甲醛原位固定，直接影响后续切片的形态与抗原保存。

[【第六期 3min 轻松高效小鼠心脏灌流 这才是关键！】](https://www.bilibili.com/video/BV1L3PFzSEHG)
- 无止血夹可直接用手（拇指）固定心脏；无灌流泵可用注射器手动缓推

[【第三期 1分钟无损取全脑，这才是关键！】](https://www.bilibili.com/video/BV1cMmGBpEB3)
- 灌流后约 1 分钟完整取出鼠脑

## 1.2 包埋（OCT，用于冰冻切片）

注意：包埋之前，组织需先完成**固定**（如灌流固定/后固定）与**脱水**（蔗糖梯度，视频资料暂未收录）；此处为 **OCT 包埋**（用于冰冻切片），**石蜡包埋**（用于石蜡切片）后续再更新。

[【脑冰冻切片样本包埋操作指南（手把手教学）】](https://www.bilibili.com/video/BV1pANGzqEDD)
